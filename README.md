# شجرة حديث الصباح والمساء

أنساب شخصيات رواية **«حديث الصباح والمساء»** لنجيب محفوظ (١٩٨٧) — ٩٦ شخصية، ستة أجيال، أربعة فروع:
آل يزيد المصري، وآل داود، وآل المراكيبي، وآل القليوبي — مستخرجة من متن الرواية صفحةً صفحة، لا من مصادر خارجية.

## الصفحتان

| | |
|---|---|
| [الشجرة النهارية](https://ahmedhaz.github.io/hadith-family-tree/) | مخطط واضح بأشرطة الأجيال، بحث، وتصفية بالفرع، وسيرة لكل شخصية |
| [كوكبة الأسرة — النسخة الليلية](https://ahmedhaz.github.io/hadith-family-tree/night/) | خلفية داكنة، إضاءة النسب بالمرور، كشف الأجيال بخط زمني، ومسار القرابة بين أي اسمين |

## ملاحظة على القراءة

الرواية تخلط الأجيال عمدًا: عطا المراكيبي أنجب محمود وأحمد «على كبر» بعد ثرائه،
فصار أبناؤهما في صفٍّ أعلى ممن يوازونهم سنًّا في آل عمرو؛ ولذلك تزوج حامد بن عمرو من شكيرة بنت محمود وهي في صفّ أبيه.
