# شجرة حديث الصباح والمساء

شجرة نسب تفاعلية لعائلات رواية **«حديث الصباح والمساء»** لنجيب محفوظ (١٩٨٧):
٩٦ شخصية عبر ستة أجيال وأربعة فروع — آل يزيد المصري، وآل داود، وآل المراكيبي، وآل القليوبي —
مستخرجة من متن الرواية صفحةً صفحة، لا من مصادر خارجية.

الصفحة المنشورة: https://ahmedhaz.github.io/hadith-family-tree/

- `index.html` — الصفحة التفاعلية: اضغط أي اسم لقراءة سيرته، مع بحث وتصفية بالفرع وتكبير.

**ملاحظة على القراءة:** الرواية تخلط الأجيال عمدًا — عطا المراكيبي أنجب محمود وأحمد «على كبر» بعد ثرائه،
فصار أبناؤهما في صفٍّ أعلى ممن يوازونهم سنًّا في آل عمرو؛ ولذلك تزوج حامد بن عمرو من شكيرة بنت محمود وهي في صفّ أبيه.
